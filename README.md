# Task Manager API

REST API для управления задачами, реализованное на **FastAPI**. Данные хранятся в памяти процесса (in-memory).

## Эндпоинты

### POST `/tasks`

Создать новую задачу.

- **summary:** Создание задачи
- **description:** Создаёт задачу с указанными названием, описанием и приоритетом. Возвращает созданную задачу со сгенерированным идентификатором.

**Статус-код:** `201 Created`

**Тело запроса** — модель `TaskCreate` (см. ниже).

**Ответ** — модель `TaskResponse` (см. ниже).

---

### GET `/tasks/{task_id}`

Получить задачу по идентификатору.

- **summary:** Получить задачу
- **description:** Возвращает задачу с указанным идентификатором. Если задача не найдена — возвращает ошибку 404.

**Параметры пути:**

| Параметр  | Расположение | Тип | Обязательный | Описание                       |
|-----------|--------------|-----|--------------|--------------------------------|
| `task_id` | path         | int | да           | Идентификатор задачи           |

**Статус-код:** `200 OK`

**Ответ** — модель `TaskResponse` (см. ниже).

---

## Модели данных

### TaskCreate

Модель для создания задачи.

| Поле             | Тип          | Обязательный | Ограничения                                     |
|------------------|--------------|--------------|-------------------------------------------------|
| `title`          | `str`        | да           | от 3 до 100 символов, не может состоять только из пробелов |
| `description`    | `str \| None`| нет          | Описание задачи (по умолчанию — `None`)          |
| `priority`       | `int`        | да           | от 1 до 5 включительно                          |

**Пример тела запроса:**

```json
{
  "title": "Изучить FastAPI",
  "description": "Прочитать документацию",
  "priority": 3
}
```

---

### TaskResponse

Модель ответа с данными задачи.

| Поле             | Тип          | Описание                     |
|------------------|--------------|------------------------------|
| `id`             | `int`        | Уникальный идентификатор задачи |
| `title`          | `str`        | Название задачи              |
| `description`    | `str \| None`| Описание задачи              |
| `priority`       | `int`        | Приоритет (1–5)             |

**Пример ответа:**

```json
{
  "id": 1,
  "title": "Изучить FastAPI",
  "description": "Прочитать документацию",
  "priority": 3
}
```

---

## Ошибки

| Статус-код | Ситуация                                       | Тело ответа                                                                                           |
|------------|------------------------------------------------|-------------------------------------------------------------------------------------------------------|
| `404`      | Задача с указанным `task_id` не найдена         | `{"detail": "Task not found", "task_id": <int>}`                                                       |
| `422`      | Ошибка валидации входных данных (Pydantic)     | Стандартный ответ FastAPI с перечнем ошибок валидации                                                 |

### Детали ошибок

- **404 Not Found** — возвращается, когда в пути `GET /tasks/{task_id}` указан идентификатор, который не существует в текущем хранилище задач. В ответе передаётся `task_id`, чтобы клиент понимал, какой именно идентификатор не найден.

- **422 Unprocessable Entity** — возвращается FastAPI автоматически, если тело запроса не проходит валидацию по модели `TaskCreate`. Примеры:
  - `title` короче 3 символов или длиннее 100;
  - `title` состоит только из пробелов;
  - `priority` вне диапазона 1–5;
  - отсутствует обязательное поле `title` или `priority`.
